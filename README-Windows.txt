DeepCurrent Windows Test v0.1

This is an experimental Windows build.

Requirements:
Windows 10/11, 64-bit.

How to use:
1. Extract the downloaded ZIP.
2. Open the DeepCurrent folder.
3. Double-click DeepCurrent.exe.
4. Test web browsing, ChatGPT, Music Station login,
   remote music library, playback and volume.

Keep the entire DeepCurrent folder together.

Configuration:
%APPDATA%\DeepCurrent\deepcurrent_config.json

This version has not yet passed Windows runtime testing.
Do not enter sensitive credentials until you trust the
test build and its distribution source.
